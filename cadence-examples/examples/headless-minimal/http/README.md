# Controlled HTTP version reference

This optional **TEST/reference** sample joins DASOps's version resource with
Cadence's offline declaration projection. It grants no production authority,
starts no listener automatically, and leaves the legacy example usable.

`openapi.json` authors intended operations/security/parameters; the actual
registrations/enforcement come from `dasops.protected.candidates.http_reference`.
`declaration.json` pins original OpenAPI bytes and the sole protocol intent
schema. Inventory is generated by `cadence contracts http-inventory --probe`,
never edited as a second author. Re-pinning candidate bytes does not approve
surface/identity changes. Coverage needs an independent approved baseline and
actual registered-route observations; missing observations remain unknown.

- `GET /target` returns the fully checked current target and strong candidate
  tag. Optional `businessActionId` queries the original native integration
  receipt; `null` remains unknown, not permission to execute again.
- `PUT /integrations` consumes the exact retained durable intent, one explicit
  strong `If-Match`, installed resource/instance and matching `Idempotency-Key`.
  Native generation, task/cycle, current authorization and I-specific evidence
  still fence the actual SQL CAS. Replay returns the original receipt without
  another reservation/effect. Completion stays in its existing protected path.
- `ReferenceHTTPAdapter` makes one send per outbox dispatch/lookup, to a fixed
  loopback address; no redirects or automatic retries. HTTP 202, transport loss
  and absence remain unknown. DurableOutbox's independent native verifier
  decides confirmation, followed by the original current Completion checks.

The HTTP/1.1 server binds `127.0.0.1`, requires exact Host, bounds body/chunks and
uses a cumulative two-second input deadline. TE+CL, repeated framing fields
(including equal lengths), LF-only/folded headers, malformed/truncated chunks
and early data close the connection before effects. Bare normal chunking and
reuse have positive tests. Chunk extensions/trailers, `Expect`, Range, proxies,
TLS and early-data activation are unsupported; their safety is not claimed.

The native JSON projection supports OpenAPI **3.0.3/3.1.1**, distinct dialect
labels/non-OAuth role rules, root/operation overrides and security OR/AND/anonymous
alternatives. It locks eight documents/one MiB total, 1,024 operations, 4,096
reference targets and bounded traversal. Locked relative references, embedded
schema `$id` bases and pointer recursion work offline. Dynamic references/
anchors, callbacks, webhooks, overlays, YAML and other dialects fail explicitly.
Literal property names and example/default instance values are not reference
authors. This is a declaration projection, **not complete OpenAPI/request schema
validation**: `schemaValidation: false`, coverage `unknown`, authority and
qualification `false`. Business-semantic compatibility still requires review.

Run the locked source drivers from repository root:

```bash
python -B -m pytest -q -p no:cacheprovider tests/integration/test_http_inventory_exchange.py tests/das_v1_5/test_a26_http_inventory.py
```

From `dasops/`, run `tests/protected/test_http_reference.py`. These use ephemeral
TEST token mappings, real loopback sockets, native Go/Python contracts and the
existing private SQLite store. Evidence stays outside Git. Production must
separately supply authenticated identities/current authorization/time,
NativeQualification, immutable originals, approved deployment/support inputs
and final installed-byte acceptance; source-built binaries do not prove these.

Native semantics: [OpenAPI 3.1.1](https://spec.openapis.org/oas/v3.1.1.html),
[OpenAPI 3.0.3](https://spec.openapis.org/oas/v3.0.3.html),
[HTTP/1.1 framing](https://www.rfc-editor.org/rfc/rfc9112.html).
