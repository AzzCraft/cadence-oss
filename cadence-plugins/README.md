# cadence-plugins

Official plugins for Cadence Core.

## Why
Cadence Core stays language-agnostic and offline deterministic. Language/framework specifics live in plugins.

## Included
- `plugins/ts` — TypeScript boundary analyzer
- `plugins/python` — Python boundary analyzer
- `bridge/eslint` — deterministic ESLint-style bridge adapter
- `bridge/prettier` — deterministic Prettier-style bridge adapter
- `bridge/ruff` — deterministic Ruff-style bridge adapter

Protocol: batch request/response JSON (see cadence-protocol).
