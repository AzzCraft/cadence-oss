# cadence-policy-packs

Policy packs for Cadence.

## Concepts
- A *policy pack* is a versioned bundle of rules + parameters.
- Cadence Core consumes policy packs during `verify`.
- Policy packs can be distributed offline (vendored) or via Control Plane registry.

## Layout
- `packs/` — versioned packs
- `docs/` — authoring guide
- `examples/` — sample configurations
